
To run these examples:
```
pyroduct run example/transform/pipeline.yaml example/transform/data.jsonl -o example/transform/
```
Of if you want to use the TUI:
```
pyroduct tui example/transform/pipeline.yaml example/transform/data.jsonl -o example/transform/
```

The tui will maintain a second pipeline in `pipeline.tui.json` that you can edit.
